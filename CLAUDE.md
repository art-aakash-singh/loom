# Loom

A ChatGPT-style AI product built to learn how such systems work from the inside.

**Current phase: 1, M0** (monorepo scaffold, /health, generated client)

## Stack
- Backend: Python 3.13, FastAPI, Pydantic v2, pydantic-settings, uv (workspace member `apps/api`)
- Frontend: React + Vite + TypeScript, pnpm (`apps/web`), client generated by openapi-typescript + openapi-fetch
- Infra: Postgres 17, Redis 7 via docker-compose
- Quality: ruff, mypy (strict), pytest (+pytest-asyncio), eslint, vitest

## Commands (run from repo root)
- `just setup` – install Python + JS deps
- `just dev` – start Postgres/Redis, then API (:8000) and web (:5173)
- `just test` / `just lint` / `just fmt`
- `just gen-client` – dump OpenAPI from FastAPI → regenerate `apps/web/src/api/schema.d.ts`. Re-run after any API schema change; never hand-edit the generated file.

## Layering rule
`routers → services → repositories`. Routers do HTTP only (parse, call a service, shape the response). Services hold business logic and never import FastAPI. Repositories are the only layer that touches Postgres/Redis. Dependencies point downward only.

## Conventions
- Everything on the request path is `async`; no blocking calls on the event loop.
- Env config via `LOOM_*` vars (see `.env.example`), read only in `config.py`.
- TypeScript pinned to 5.x: openapi-typescript needs the JS compiler API that TS 7 removed.
